# 手动验收清单

适用于 **0.4.17**。以下均为**待执行步骤，不是通过记录**。每次验收单独记录日期、模组版本、环境、实际结果及截图或日志；未安装的附属标为“不适用”，未执行的项目保持“待测”。自动化测试与运行方法见[开发说明](DEVELOPMENT.md)。

## 准备

- [ ] 使用测试存档；记录 Minecraft、Forge、AE2、本模组、相关附属及保护模组版本。多人测试保持两端版本一致。
- [ ] 搭建有能源和空余频道的网络：两个驱动器、一个 ME 箱子、一个存储总线箱子。准备已知数量的物品、不同 NBT 的同名物品和流体。
- [ ] 准备有限能源元件，便于断电验收；可选附属分别准备 ExtendedAE 扩展驱动器／无限元件、OmniCells 元件、Mekanism 与 Applied Mekanistics 容器。

## 连接、浏览与显示

- [ ] 合成、放置并打开控制器。断电或耗尽频道后应离线，恢复条件后可继续使用；方块在线显示与实际状态一致。
- [ ] 逐级选择网络、设备和元件，再返回。核对名称、维度、坐标、容量及已知资源数量；同名不同 NBT 条目不合并。
- [ ] 对照 AE2 原生提示检查物品、流体元件容量。未知容量不显示为零或无限，不生成虚假百分比；大容量文本不遮挡类型数。
- [ ] 在多页内容中搜索、清空、按名称／数量排序、切换范围。结果和页码及时更新，不残留上一范围内容。目录搜索与内容搜索互不干扰。
- [ ] 检查浅色／深色、中文／英文、长名称和输入框。搜索及文件夹名称文字无阴影；悬停只显示一份清晰提示框。

## 滚动、比例与状态

- [ ] 在内容网格、滑轨、上下箭头上快速滚动并立即反向，再拖动滑块到两端。位置连续响应，旧响应不会拉回新目标；背包和搜索框上的滚轮不滚动内容。
- [ ] 在固定比例与“自动”比例下打开、关闭并调整窗口，检查 1920×1080、1280×720、960×720。原生 GUI 比例不变，控件与槽位可用；窄屏能切换目录并取放元件。
- [ ] 输入查询、移动输入光标、选择元件并折叠目录后调整窗口。文字、选择、折叠及仍可见输入框的焦点／光标保持。
- [ ] 关闭重开并重启游戏，确认个人折叠状态恢复；换控制器、世界或玩家不串状态。大型目录滚动到底，末尾设备／元件仍可访问。
- [ ] 手持物品打开侧栏 ? 指南并按 Esc 返回。原菜单、范围、光标物品保持，下一次取放正常；指南快捷键及改绑后入口可用。

## 元件与普通物品

- [ ] 从驱动器、ME 箱子取出含已知内容的元件再插回，比较内容和 NBT。普通点击、Shift、快速连续点击、满背包均不复制或丢失元件；石头等非元件不能放进元件槽。
- [ ] 在网络、设备、单元件范围分别执行[使用指南](USER_GUIDE.md#存取物品)中的左／右／Shift 操作、空格存入和背包 Shift 存入。核对存储、背包、鼠标的总数；选择单元件时其他元件不变。
- [ ] 测试最大堆叠数为 1、16、64 的物品，以及背包仅剩部分空间、元件已满的情况。剩余物品留在正确位置。
- [ ] 耗尽实际 AE 缓存，确认存入和取出都被拒绝；补充能源后恢复正常。操作消耗原生 AE 能量。
- [ ] 可选 ExtendedAE：选择第 20 个元件，从第 11–20 槽页取出并插回，核对真实槽位与内容。

## 容器与附属资源

- [ ] 持空桶或兼容容器左键资源进行填充，普通右键资源格／空白格倒入；分别在网络、设备和元件范围核对资源与容器总量。
- [ ] Shift 左键填充单个容器，测试空背包与满背包，放不下的结果留在鼠标。另测堆叠容器，把原生策略可能产生的掉落实体计入总量。
- [ ] 空手左键水或熔岩，测试当前范围有／无空桶；桶仅在其他范围时不得借用。填充失败的桶退回原范围或保留鼠标。
- [ ] 测试不足一桶的余量／空间、混装拒绝、无电和过滤拒绝。失败不能改为存入整个容器，也不能跨范围转移资源。
- [ ] 可选化学品：按具体资源和容器分别验证填充、倒空与 Shift 填充，转移量对照容器原生速率。未注册容器策略的资源仅确认可浏览，不把它记为可取出。
- [ ] 可选无限元件：分别配置熔岩和物质球，核对名称及 ∞。同种资源的普通元件仍显示有限数量；切换网络、文件夹、元件范围后标记正确。
- [ ] 可选 OmniCells：检查混合资源、有限字节／无限类型、BigInteger 容量显示，以及元件移出重入后的数据；不能可靠读取的占用保留未知。

## 文件夹与多人一致性

- [ ] Ctrl 多选、Shift 范围选择后新建归组；创建子文件夹、重命名、移入和移出。右键菜单不切换当前存取范围，整理前后实际元件及资源不变。
- [ ] 选择嵌套文件夹，核对成员汇总与实际存取。非成员不受影响；整设备与其槽位同在汇总范围时不重复计数。
- [ ] 将单槽归组后取出并换入元件，分类跟随槽位。另行归组单槽不会从整设备成员的范围中排除它。
- [ ] 删除文件夹，直接成员与子文件夹提升到父级，实物不变。移除或断开成员设备后分类保留，相关文件夹暂不可存取；重连后恢复。
- [ ] 两名玩家或同网两个控制器查看同一分类，编辑结果同步；各自展开／折叠互不影响。测试网络分裂与重连后的分类合并及成员可访问性。
- [ ] 两人同时取出最后一组物品或同一元件，核对服务端与双方库存总数。另一人换芯、拆设备或切断连接时，旧界面不能操作失效目标或越过范围。

## 外部存储、权限与定位

- [ ] 存储总线连接双箱、方向受限容器和储罐；分别配置过滤、只插入、只提取。内容与实际连接面一致，物理容量与可访问内容不混淆。
- [ ] 同一外部库存存在多条访问路径时，对照 AE2 终端核对全网内容；文件夹拒绝不安全的重叠范围。未知第三方设备不伪造容量或可编辑槽位。
- [ ] 使用真实受限玩家和领地保护配置测试元件及内容操作；被禁止的目标不可存取。跨维度、区块卸载、设备替换后也不能沿旧目标操作。
- [ ] 定位同维度已加载且 256 格内的设备，移动／旋转镜头确认线框贴合目标并在约 15 秒后消失。总线应定位容器；无效、远处或跨维度目标不强制加载区块。
