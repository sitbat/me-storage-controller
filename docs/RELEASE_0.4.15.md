# 0.4.15 文件夹输入框样式

- 将“移出到网络根目录”改为“移出文件夹”，英文对应为“Move out of folder”。该操作的归组行为不变。
- 新建／重命名文件夹的输入框使用平面背景，去掉深色边条和文字阴影。
- 保留原版文字编辑、光标、选区及横向滚动行为，其余布局不变。

协议继续使用 9，与 0.4.14 的存储和文件夹数据格式一致。

构建和现有 13 项单元测试通过。本次为局部文字与绘制调整，没有重跑 0.4.14 的整套游戏内验收。

This visual update renames the folder removal action and removes the folder name field's recessed border and text shadow. Native editing and selection behavior are retained. Protocol 9 and persisted storage/folder data remain unchanged.
