Adaptation by ME Storage Controller contributors:
The thirteen copied PNG files are byte-for-byte unmodified. Texture regions,
UV coordinates, colors, layout and combinations are selected by this addon's
independent drawing code and JSON models. The controller is a custom box/frame
with AE2 monitor textures and three terminal masks. The GUI recombines portions
of upstream terminal/background/widget textures with this addon's file tree.
Derived JSON models and these visual adaptations are also provided under
CC BY-NC-SA 3.0. Rendering and lighting are adapted to Forge 1.20.1; this is
not an official AE2 block or screen, nor an endorsement by the original authors.
